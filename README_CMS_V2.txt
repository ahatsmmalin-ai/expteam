EXPERT TEAM — CMS V2 / ВИЗУАЛЬНЫЙ РЕДАКТОР
==========================================

Это ДОПОЛНЕНИЕ к уже работающей CMS, а не полная копия исходного проекта.
Пакет сохраняет все опубликованные изменения, внесённые через CMS ранее.

ЧТО ЗАГРУЖАТЬ
-------------
1. Откройте https://github.com/ahatsmmalin-ai/expteam в ветке main.
2. При необходимости создайте резервную ветку.
3. Распакуйте архив и загрузите его содержимое в КОРЕНЬ репозитория:
   - pages_build.py (заменяет существующий сборщик)
   - edit/index.html
   - edit/editor.css
   - edit/editor.js
   - edit/preview.css
   - ИНСТРУКЦИЯ_CMS_V2.txt (необязательно)
4. СОХРАНЯЙТЕ остальные файлы без изменений, прежде всего content/ и templates/.
   Не удаляйте папки, не загружайте в корень какой-то старый полный ZIP!
5. Cloudflare продолжает использовать прежние настройки:
   pip install -r requirements.txt && python pages_build.py
   Build output directory: dist
6. После нового успешного деплоя откройте:
   https://expteam-staging.pages.dev/edit/

ПРОЦЕСС
-------
- Нажмите «Войти через GitHub». OAuth-приложение, как и для /admin/,
  использует существующий endpoint /api/auth.
- Доступ к правкам только для пользователей, у которых есть права записи
  в репозиторий ahatsmmalin-ai/expteam. Гостям доступны только просмотры.
- Откройте страницу через меню или выпадающий список в верхней панели.
- Наведите на заголовок/текст: появится значок карандаша. Нажмите на текст,
  правка откроется справа и сразу отразится в предварительном просмотре.
- «Отправить на согласование» создаст отдельную ветку и Pull Request в GitHub.
  Текущий публичный сайт не меняется до утверждения и объединения Pull Request.
- Откройте ссылку на Pull Request, проверьте текст, выполните Merge.
  Cloudflare автоматически пересоберёт сайт из ветки main.
- Если другой редактор уже изменил тот же файл, редактор НЕ перезапишет
  изменения: он сообщит о конфликте и попросит перезагрузить страницу.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
------------------------
- Визуальный режим позволяет редактировать ТЕКСТЫ 38 существующих страниц
  и общие тексты сайта. Создание новых блоков и перестановка секций —
  по-прежнему через шаблоны/код.
- SEO-поля Title/Description, новые статьи, изображения, контакты и новые
  страницы редактируются в существующей админке /admin/.
- После сохранения в PR эти правки появятся в опубликованном сайте только
  после Merge и успешного Cloudflare Deployment.
- В обычном посещении сайта карандаши НЕ отображаются; они показываются
  только внутри визуального редактора. GitHub-токен не хранится в браузере
  после закрытия/обновления вкладки; при новом открытии понадобится вход.
- Для визуального редактора используйте основной тестовый адрес
  https://expteam-staging.pages.dev, а не URL отдельного deployment.
- CMS и редактор не заменяют подключения заявок к CRM и аналитики.

БЕЗОПАСНОСТЬ
------------
- Ни Client Secret, ни PAT не должны попадать в GitHub, ZIP и скриншоты.
- Оставьте имеющиеся секреты Cloudflare GITHUB_CLIENT_ID/GITHUB_CLIENT_SECRET.
- GitHub OAuth scope repo даёт широкие права; не давайте доступ незнакомым.
- Сайт и репозиторий пока могут быть публично доступны. Не публикуйте
  конфиденциальные материалы в тексте, даже в ветках с черновиками.
