# Памятка SEO-специалисту: что изменять в CMS после подключения

| Задача | Раздел будущей админки | Поля |
|---|---|---|
| Написать новую статью | **SEO-блог** → Новая запись | H1, URL, ключ, рубрика, автор, текст, обложка, alt, SEO Description, связанные услуги |
| Исправить статью | **SEO-блог** → Найти по названию | Текст, дата обновления, SEO Description, обложка |
| Изменить услугу | **Услуги (7 страниц)** | H1, Title, Description, оффер, сегменты, этапы, FAQ |
| Дополнить SEO-разделы | **SEO-блоки страниц услуг** | H2, содержание |
| Добавить произвольную страницу | **Новые страницы (конструктор)** | Выбрать раздел URL, slug, Title/Description/H1, текст, CTA, иллюстрацию |
| Изменить SEO главной или контактов | **Настройки** → SEO | Title, Description |
| Изменить цены | **Настройки** → Тарифы | Стоимость, описание, состав пакета |
| Добавить кейс | **Кейсы** → Новая запись | Клиент, показатели, результаты, подтверждения, SEO Title |

**Проверки:** slug — только латиница/цифры/дефис; нельзя создать страницу внутри `/uslugi/` через конструктор; публикации требуют редакторского согласования. Для статьи нужны реальный автор, источники фактов и минимум 1500 слов при выпуске. Нельзя считать кнопку «Опубликовано» единственным этапом одобрения: и GitHub editorial workflow, и наши проверки должны пропустить материал.

**Сейчас входа в CMS ещё нет.** Для корпоративной демонстрации предоставлен локальный HTML, где можно просматривать страницы и оформление, но нельзя сохранять CMS-правки через браузер без GitHub.
