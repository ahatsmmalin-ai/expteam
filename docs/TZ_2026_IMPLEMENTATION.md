## Что не готово к публичному коммерческому запуску

1. Заявки в CRM **не отправляются**. На staging показывается честное сообщение; в финальном release обязателен HTTPS-обработчик и подтверждение успеха.
2. CMS не авторизована. Работа с JSON/Markdown и автосборка доказаны, но **вход и сохранение из браузера не тестировались**.
3. Нет оригинального логотипа в файлах: оставлен аккуратный типографический знак для замены.
4. Нет настоящих фото команды и благодарственных писем. Плейсхолдеры подписаны.
5. Кейсы из ТЗ требуют проверки фактов, периодов, классификации заявок и согласия на публикацию. Описания без выдуманных промежуточных цифр.
6. Юридическая политика не утверждена; производственная индексация отключена. Release gate блокирует запуск.
7. Не подключены Яндекс.Метрика, Яндекс.Вебмастер, Google Search Console — подготовлены события и SEO-файлы, но ID/учётные записи пока нет.
8. `expertteam.pro` не менялся — сайт подготовлен только для обновления `expteam-staging.pages.dev`.

## Технический статус

- `python build.py` — полный noindex-сайт из контентных файлов.
- `python scripts/redesign_qa.py` — проверка страниц, ассетов, ссылок.
- `python scripts/redesign_cms_smoke.py` — симуляция редактирования и новой CMS-страницы; не OAuth.
- `EXPERTTEAM_INTERNAL_REVIEW=YES python pages_build.py` — та же команда, которую вызывает Cloudflare Pages.
